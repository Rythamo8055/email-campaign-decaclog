## 1. VIDEO 1 — I Tested 40 FREE Email Tools (650 subs, musician, 3-4 emails/year, simple blue-link + album art)

- Started 40 tools → 23 had **NO free plan** (just “free trial” with pricing page gray text)

- Most free plans cap contacts — eliminated any <650
- **Exception excluded:** Brevo (300/day) + Flowdes? Flodesk (500/day) have unlimited contacts but daily send cap too low for one blast → eliminated
- Survivors: **8 tools** → deep dive

### 1.3 Domain Authentication Reality
- 2024 Gmail/Yahoo rule: **custom domain verification mandatory** (SPF/DKIM/DMARC)
- Manual DNS = risk (can break website/email — MailerCloud asks delete record)
- Automated verification (MailerLite 20-sec tool) >>> manual
- Single TXT (Mailjet) easiest manual
- Gmail sender = flagged, deliverability will suffer without auth

## 2. VIDEO 2 — 1 Billion Emails: 7 Lessons That Double Sales In Days

### 2.1 #1 Customers Crave NEW (Dopamine)
- Inbox more competitive than ever — avg customer subscribed to **50+ newsletters**
- Boring = recycled content + same template every send → instant death
- **Fix content angles** — rotate: customer story → mythbusting → sneak peek → “ChatGPT rated our products” → puzzle/quiz mystery discount → NEVER product highlight → testimonial loop
- **Fix designs** — never reuse template; switch layout/order, long vs short form, infographics vs blocks; newness = dopamine = open
- If they know exactly what they’ll get, they won’t click

### 2.2 #2 Traffic Before Copy
- Best copy useless with 0 list — 10 audits/week: “awesome emails but 0 people receiving” → results bad
- Must drive eyeballs: Meta ads / organic / SEO / influencers / partnerships — doesn’t matter, just capture
- **Newest leads (0-30 days) = hottest** — 100k stale list < fresh 30-day leads; always grow list

### 2.3 #3 Text-Based Emails (1 in 5)
- Graphic-heavy = pretty but feels like ad; text-based (plain, founder-signed) feels like friend → breaks noise, gets replies, higher CTR/revenue
- Use sparingly or loses power → **1 of every 5 campaigns**
- Where: welcome from founder, abandoned cart/checkout support-style, winback/post-purchase mission reminder
- Majority stays graphic for branding/dopamine

### 2.4 #4 Don't Over-Engineer Flows
- Trap: 12-email flows, 87 splits, product/persona branches → 80% revenue from **first 1-3 emails**
- Start broad: **2-3 killer emails** per flow → welcome, browse abandon, cart abandon, checkout abandon, post-purchase → test then expand
- Small splits (4 branches × 1000 = 250 each) → no statistical significance; keep 1 path × 1000 → test faster

### 2.5 #5 Stop Over-Segmentation
- Don’t need 87 lists (product/gender/location/birthday/underwear-Tuesday)
- Only segment that matters: **engaged 30/60/90 days** (opened/clicked/active)
- Cast wide net × high frequency > hyper-niche × 4 sends to 20k
- Frequency first, segmentation second; never blast full unengaged list → spam folder

### 2.6 #6 Pop-Up = #1 Leverage
- Most overlooked — avg 3% conversion → clients avg **10%** → 3× list growth → 3× revenue over 3 years
- Tweaks to copy/offer/design can triple pop-up rate quickly
- Also **reduces CAC** — captures ad traffic that would otherwise leave forever + nurtures to purchase

### 2.7 #7 Frequency Is King
- 95% of 7-9 figure brands **under-send** → buried
- 1/month or 1/week = forgotten, leaves meat on bone
- **Optimal 3-4×/week** (every other day) — daily = unsubscribe spike; every-other-day = expected presence
- Counter-intuitive: consistent 3-4× gets **fewer unsubscribes** than random monthly blast (when rare, blast feels like surprise → unsubscribe)
- Only works if obeying #1 (new/dopamine content)

## 3. VIDEO 3 — Cold Email 7-Hour Masterclass (Under $100 System) — Outline → Bullets

### 3.1 Why Cold Email
- **Highest value skill** — prints money any business (Inc 5000 PR agency 60 employees built on it)
- Control vs ads/SEO/social: you own list, no platform shutdown (Google/FB always screws you)
- **Pennies per lead** (<$1 per 1k = 100× cheaper than ads), scalable/predictable (equation fills sales calendar), instant (turn on → leads) vs years for SEO/YT
- Fully legal (CAN-SPAM)
- Perfect for **B2B** (target by owner/founder/CEO + industry); B2C only if high-ticket or to get distributors/retailers (Publix/Walmart), plus operational (PR → journalists)

### 3.2 Cold vs Warm
- **Cold:** first contact, never opted-in → belongs in **cold CRM** (Instantly/Smartlead/ReachInbox) separate infrastructure
- **Warm:** opted-in (form/iPad/meeting) → main CRM (Mailchimp/ActiveCampaign/HubSpot/GHL/Salesforce)
- Only moves cold→warm after they opt/book — never mix

### 3.3 Costs (<$100/mo starter)
- Cold tool $37/mo (Instantly/Smartlead/ReachInbox)
- Leads $50 / 10k (TrustedLeads/Apollo scraping)
- Mailboxes $3/mo each (via reseller) — Google retail $8.40, MS similar
- Domains $8.88 on Spaceship (vs GoDaddy $12 → renews 2-3×); scales to thousands/mo but still cheaper than ads 10×

### 3.4 Myths
- **NOT easy:** 10k things can break, 60% fail without 3 pillars
- **NOT dead:** competition fierce but practices/tools better than ever → 87-100% inbox still possible
- **NOT technical:** DNS/mailbox setup now 30-min recipe (no IT)
- **NOT expensive:** race to bottom for data/infra

### 3.5 The 3 Pillars Pyramid (bottom up)
- **P1 Technical (foundation)** — IP + domain + mailbox + DNS (DKIM/SPF/DMARC/MX). If inbox fails, rest irrelevant. Easiest to get right: follow recipe, never cut corners.
- **P2 List** — right person + valid email + qualified fit. Wrong industry/title/retired/invalid = spam report → kills P1 rep.
- **P3 Offer & Copy** — hardest, no template, need real problem + unique mechanism + trust. Own P1/P2 before fancy.

### 3.6 Fundamentals > Fancy
- Best campaigns = **NO AI personalization** — master pillars first, then add AI

### 3.7 Technical Infrastructure Deep Dive

#### IP / Domain / Mailbox Reputation Hierarchy
- **IP (server) most important** → Domain → Mailbox individual
- One spam report can burn mailbox; many reports/blacklist burns entire domain → all mailboxes under it dead
- Never cold-mail from primary domain — sacred

#### ESP Choice
- **Google 87.2% inbox** — still best even to Microsoft inboxes; provider matching myth (sending MS→MS not better)
- **Microsoft 75.6%** — enterprise uses MS more, small/mid uses Google
- **Custom unmanaged SMTP** (Mailin/InfraMail ~$1/mo or $99 unlimited 1 IP) — you own IP risk → 1 spam trap burns all domains/mailboxes overnight — only for experts with low spam rate
- **Managed SMTP** (Mission Inbox/Meldoso ~$5/mo + $199 setup) — company rotates/cleans IPs, still slightly worse than Google, expensive
- **Recommendation:** Google via reseller  **3$/mo** (LeadGenJay Inbox does DNS+upload+warmup+human rep), 5 mailboxes/domain, ~20-25 emails/mailbox/day = ~100/domain/day; diversify providers at scale as hedge

#### Domains Buying
- **Spaceship Beast Mode** best for bulk — filter TLDs (.com cheapest/most trusted), enter keywords (Beaver/Viral/PR) + prefix/suffix (get/my/try) → $8.88 buy $10 renew vs GoDaddy trap
- Alternatives: PorkBun/Cloudflare; keep name servers on registrar or move to Cloudflare (security, one-place DNS — not proven lift)
- Set: name servers, DNS records, **URL redirect permanent to primary domain** (propagation minutes→hours)

#### DNS Records Checklist
- **Must have:** DKIM + SPF (host @) + DMARC (host _dmarc, policy quarantine/reject, failure 0 = no reports) + MX (points/priority 1 for Google)
- Verify via **EasyDMARC / MXToolbox** scan → risk medium if DMARC not reject, else fix immediately → pause campaigns
- Generate: Google Workspace admin → DKIM generate TXT (google domain key) + SPF generator + DMARC generator
- **Custom tracking domain** (CNAME inst → Instantly value) — standard but **we DON'T use tracking/open links** (spam); only if you insert unsubscribe link else Instantly link exposes cold
- Domain age: **30 days min, 60-90 ideal** before sending; longer = safer rep
- Other: Domain masking proxy (EmailGuard) vs redirect — no difference, skip

#### Mailbox Setup
- Google Workspace: verify ownership via TXT + CNAME → add user → activate Gmail via MX → DKIM/SPF/DMARC+custom tracking → test domain setup button → all green
- Alternative reseller flow: choose count (25-50 start), buy domains yourself or easy mode they buy + forward + sender name + photo
- **Name tactic:** founder name OR 1-syllable white girl (Jen/Ruth) — best conversion
- **Never forward mailbox** to central inbox → breaks thread → reply from C = new cold → spam; stay in Instantly unibox

### 3.8 Software Stack

### 3.9 Deliverability = Deliverbaby → Expert Skill (billable)

#### Factors
- Domain config + age + reputation (spam reports countered by warmup) + IP/mailbox rep + blacklists + copy (words/links/images) + tracking code + reputation recovery

#### Warm-up
- Pool exchanges emails → removes from spam, marks important, reads/replies like human; high-quality = copy matches your cold topic + human emulation; **Warmy.io** best for primary domain (topic/ESP targeting, 1k/day, 50% off via leadgenjay) but overkill for cold; **Instantly free unlimited warmup** good enough for cold; keep **always ON** (100 cold + 100 warm = halves spam rate from 1%→0.5%); bad pool with low-rep mailboxes = damage

#### What Can Go Wrong (check order)
1. **DNS** → scan EasyDMARC
2. **Blacklists** → MXToolbox (domain worse than IP; Google IP blacklists Google rotates not worried; unmanaged IP doom); traps = landmines from blacklist companies via spam traps → lasts 30 days; if listed stop cold, warm 30 days
3. **Copy** → spam words/phrases, too much code/links (short better, no unsubscribe/opt-out words, no links in Email1)
4. **Domain age**
5. **Reputation** → Google Postmaster (domain/IP rep, spam %, delivery errors, auth) add TXT/CNAME verification for all primary + cold domains
6. **Bounces** → hard (invalid/domain) = hurts rep vs soft (full/server) less; but also blocked content/reputation bounces even if verified → check bounce reason; old list 3mo → 20% change jobs → bounces

#### Fixing Spam (same treatment)
- Pause cold 2-4 weeks (30d for blacklist) → warm only → tag “warming 2025-05-01” → slow ramp when placement >70%
- Use **Instantly inbox placement**: add test daily (North America/Europe, Google+MS filters, every mailbox, copy from campaign, delivery opt ON, 1-by-1) → automations: if <50-80% pause 14-30d + tag spam warming, if back >70% slow ramp; alternatives EmailGuard (cheap bulk), **GlockApps** gold standard (2 free/mo, shows Gmail promotions vs spam, IP analytics, SpamAssassin, Google spam filter detection)

#### Diagnostics Flow
- If reply drops overnight: check 7-day campaign analytics (2.7%→0.5%) + placement 20% drop → pause → test copy via GlockApp from real mailbox + send to self check **dangerous flag** (big red “message seems dangerous” = death warrant) → if clean then list/offer

### 3.11 Verification & Qualification (3-Layer Defense)

#### Bouncing 101
- Letter returns if address wrong; types: hard (permanent bad domain) vs soft (full/down); reason matters (content blocked = not invalid) → causes rep hit; need valid before sending

#### Layer 1: Email Verification
- Pings address → **good/ risky (catchall/unknown) / bad**; only send to good; Apollo verified still ~70-80% good → riskies = 22-28%
- Tool: **MillionVerifier $2500/10M** bulk (API to Apollo/Clay automation) vs FindEmail vs Instantly compilation; AppSumo verification okay cheap
- Riskies: catchall (server accepts all) + unknown (couldn’t tell) — **50% of riskies actually deliverable** → don’t ignore if TAM small
- Verify catchalls via **FindEmail.com** (data accumulation + emailing) → export riskies separately → upload → 3/4 valid; or **Clay**: upload once → millionVerifier api → findEmail catchall in same table (rainbow = custom API) → saves credits (million cheap first, catchall expensive second)
- Workflow: Trusted (or Apollo) → Million first → FindEmail for riskies → Clay auto
- Also verify warm CRM via **EverClean** or GHL checkbox “validate on entry”

#### Layer 2: AI Qualification (200-300% lift)
- AI reviews each lead (company description/industry/title/website scrape) → prompt decides fit → eliminates 30-50% unfit → reply 2-3×, spam down
- Cost: 2× data need + Clay $350 explorer + OpenAI; but TAM large tolerates shrink
- Prompt: `You're expert sales assistant... Use knowledge of industry/company to decide if they have use for my offer [I help X with Y]. Here company info {...}. Output yes/no only.`
- Options: Clay clagent research (best, scrapes web) vs SheetMagic/Google Sheets vs Instantly AI templates (cheap no web)

### 3.14 Copywriting — Triple Tap

#### Tap1 Open (Preview Text)
- Sender + subject + first sentence decides open/report/trash; **never signal sale** before open
- Must look like client/vendor; question triggers instinct to answer: old “Question Jay?” still tests well but may be flagged now
- Good: subject “Sending cold emails?” first “Not sure if you’re sending these or not. Jay, mind checking?”; “Is this you on Google? Just came across this on Google. Can you confirm this is you?” → then body ranks #8 and offers help
- Test via reply rate proxy (no open tracking)

#### Tap2 Read (Body 2-3 sentences, middle school, short punchy)
- Must do: call out problem + solution mechanism + build trust/credibility authentically (not brag)
- Personalize problem (their day-to-day pain) + social proof (case study of known competitor in same industry > random)
- Example: “Currently running outbound for LeadGenJay. After seeing crazy success thought I could do same for you. Here’s USA Today article about my methods.” + “If you already have more calls than you can handle ignore me. If want outbound machine love to show strategy.”

#### Tap3 Action (CTA — reply with 1 word)
- No links/clicks/thinking → “yes/sure/send it” one hand 1 min
- “Would it be cool if I send over strategy? → yes”; goal = hand raise → sales starts

#### Golden Rules
- 6 sentences max, 6th grade, Claude simplifies; tone matches ICP (humor 20s Miami agency, feminine delicate cosmetics/fashion, sales talk 50s car dealer); use AI to adjust tone
- Low resistance CTA; credibility via same-industry case study (buy free job for anchor if none) / followers/YouTube/media; specific mechanism (not “100 leads 30 days money back” without how)
- **Don’ts:** overpromise, vague mechanism, confuse, bait-switch subject↔body, salesy promo language

#### Personalization
- **Always firstName** → works; more not better (company with LLC/caps screams cold, location often wrong); AI personalization hurts 95% if wrong

#### Spintax Mandatory
- `{{hi|hello|hey}}` `{random|what’s up|how you doing}` prevents ESP repeat phrase flag; preview variations via AI “show all variations” to catch nonsense; generate via Instantly AI spintax writer + spam checker, or custom Jay GPT

#### Sequences
- Shorter = more leads reached; Email1 does 80% work; more emails = more spam reports; **MAX 3, space 2-5 days**
- **Email1:** triple tap, AB test heavy
- **Email2:** same thread nudge bump — “Whats up {{firstName}} did you catch my email yesterday? It was about your email campaigns. Got a minute? If barking up wrong tree say wrong tree” humor if fits — wait 1d if says yesterday else 3d
- **Email3:** dump — case study links/video/features — same OR new thread (test “yes or no” subject)
- Short 1-2 when TAM huge/millions/cheap data/few mailboxes (max people); Extended 4-7 only when TAM tiny (<10k) + strong social proof/value per email + opt-out each time; pull different levers (money/speed/prestige, value stack/story/scarcity) each email

#### Split Testing Right Way
- **Campaigns = audience** (industry/size same copy) vs **Variations = offer/copy** (same list) — don’t mix
- First test whole offers/magnets with same subject → big delta
- Then test one element: preview vs body vs CTA need 9 variations for 3 each → copy body, paste variant, change only that element
- Add variant in Instantly: add variant button → paste → new subject “Company on USA Today”
- Also test Email2/3 thread strategy
- Interpret via **opportunities > reply**; toggle gear; share button; **statistical significance** via ChatGPT image equation + power; Instantly auto winner by reply not ideal vs opp

#### Deliverability Copy Checks
- Avoid spam words list (in resources) + check Instantly spam tool + MailMeteor/EmailGuard content checker + replace; no unsubscribe/opt-out in Email1 (friends don’t), Email2-3 add delicate “If barking up wrong tree say away and I’ll remove you” avoid word unsubscribe; warm conversation allows anything later but keep in unibox not forward; no links in Email1 plain only, Email2-3 plain not hyperlinked + only authoritative (YouTube/Calendly/Loom not fresh domain/coldemailmonsters.com/book, affects rep); pics/video generally no unless explains better (commercial window damage pic worked) test not in Email1; after reply can send anything

#### CAN-SPAM Bare Minimum
- Need opt-out + address + stop when asked + accurate header; decade zero fines even when lawyer reported to Google/GoDaddy/MS — nothing happened

### 3.18 Scaling To 10k/day & 1M/month
